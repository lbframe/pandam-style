What changed

Compilation now records every design value it emits. Reviewers compare the record with the design system definition instead of reading generated files, and the comparison fails when a value has no authorized source.

  1. Declare the vocabulary.
  2. Compose it in components.
  3. Ship the static stylesheet.

Constraints are cheaper to review than conventions.

Multi-column text keeps long reference material readable on wide screens. It flows from one column to the next without manual breaks, and collapses to a single column when the viewport becomes narrow. Hyphenation and balanced line breaks keep the right edge even.
