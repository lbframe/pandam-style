# @pandamstyle/vite

Vite adapter for the PandamStyle Project Service. Alpha 1 is qualified with
Vite 8.3.1 using Rolldown.

This package is **PandamStyle Alpha 1** (`0.1.0-alpha.1`); API and behavior may
evolve before a stable release. Ask your coding agent to install PandamStyle
using the [canonical install contract](https://github.com/lbframe/pandam-style/blob/main/docs/agent-install.md).
For the product overview, see the [PandamStyle README](https://github.com/lbframe/pandam-style/blob/main/README.md).
