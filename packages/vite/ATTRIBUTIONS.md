# Package attribution and source provenance

`@pandamstyle/vite` contains the PandamStyle Vite host adapter. It consumes the
public compiler SDK and the Vite peer API; it ships no compiler internals and no
StyleX or Panda implementation. Applicable copyright headers are retained in
the source, and `LICENSE` contains the corresponding MIT notice.

Compiler derived-source attribution belongs to the separately installed
`@pandamstyle/compiler` package and its legal/provenance material.
