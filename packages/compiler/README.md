# @pandamstyle/compiler

PandamStyle's compiler, design-system authoring API, diagnostics, and
revision-based Project Service. The package also provides the `pms-build`
binary for explicit build workflows.

This package is part of **PandamStyle Alpha 1** (`0.1.0-alpha.1`). Its API and
behavior may evolve before a stable release. For agent-led installation and
interface building, start with the [PandamStyle README](https://github.com/lbframe/pandam-style/blob/main/README.md)
and the [agent contracts](https://github.com/lbframe/pandam-style/tree/main/docs).

Host integrations are published separately as `@pandamstyle/vite`,
`@pandamstyle/next`, and `@pandamstyle/rsbuild`.
