# @pandamstyle/core

PandamStyle's small ESM composition ABI and generated-style runtime helpers.
Most application projects receive this package through `@pandamstyle/compiler`
and a host adapter.

This package is part of **PandamStyle Alpha 1** (`0.1.0-alpha.1`). Its API and
behavior may evolve before a stable release. For agent-led project setup and
usage, start with the [PandamStyle README](https://github.com/lbframe/pandam-style/blob/main/README.md)
and the [agent contracts](https://github.com/lbframe/pandam-style/tree/main/docs).

The package is ESM-only, ships its public types, and supports the Node ranges
declared in its package manifest.
