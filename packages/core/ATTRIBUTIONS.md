# Third-party attribution and source provenance

`@pandamstyle/core` contains the PandamStyle runtime ABI and composition
helpers. The package's JavaScript has no third-party runtime dependency and no
StyleX or Panda implementation. Its source files retain the applicable MIT
copyright headers; `LICENSE` carries the corresponding license text.

The compiler's derived-source mapping is maintained in the repository-wide
[`ATTRIBUTIONS.md`](https://github.com/lbframe/pandam-style/blob/main/ATTRIBUTIONS.md).
That compiler provenance does not describe code shipped in this package.
