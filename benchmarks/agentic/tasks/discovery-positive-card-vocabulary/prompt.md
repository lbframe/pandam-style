We are about to design a "compact featured product" card. Before anyone writes
code I need the exact PandamStyle vocabulary this project already offers.
Do not change any file.

Fill these keys in your report's `answers`:

- `recipe`: id of the recipe used for product cards
- `slots`: that recipe's slot names, in declaration order
- `elevations`: the allowed values of its elevation axis
- `compactRaisedRadiusToken`: the radius token applied to the card root when the
  card is both raised and compact
- `mutedTextToken`: the public color token for secondary (muted) text
