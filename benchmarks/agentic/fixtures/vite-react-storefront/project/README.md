# Storefront

Vite + React storefront styled with PandamStyle.

- Design system: `design.pandamstyle.config.js` (owned by the design team).
- Generated design module: `.pandamstyle/` (compiler output, regenerated by the
  Vite plugin; never edit by hand).
- Build: `npm run build`. Dev server: `npm run dev`.
- Keep existing `data-testid` attributes; QA automation relies on them.
