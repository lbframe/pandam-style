# Ops console

Next.js App Router with the webpack backend (`next dev --webpack`,
`next build --webpack`). Styling: PandamStyle via `@pandamstyle/next`.

- Design system: `design.pandamstyle.config.mjs`.
- PandamStyle roots: `app/` and `components/`. `lib/` holds data only.
- `.pandamstyle/` is generated by the compiler. Do not edit.
